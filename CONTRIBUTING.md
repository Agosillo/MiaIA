# Contributing to MiaIA

MiaIA is currently maintained as an author-led project. External pull requests and unsolicited code contributions are not accepted at this stage.

You may use, study, modify, and redistribute the MPL-covered source under the terms of the Mozilla Public License 2.0. The ability to fork the code does not imply that changes will be merged into the official repository.

Bug reports and focused feedback may be submitted through the repository issue tracker. Please do not include confidential information, third-party proprietary code, security-sensitive details that should not be public, or proposed patches in an issue.

This policy may change after a contribution and copyright-management process has been established.
