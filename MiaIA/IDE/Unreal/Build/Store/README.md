# Microsoft Store package

This directory contains the fixed Microsoft Store identity, manifest template,
and visual assets used by `../Package-StoreMsix.ps1`.

## Product identity

The values below come from the reserved **MiaIA Studio** product in Microsoft
Partner Center. They must remain exact in every package submitted for this
product.

| Manifest field | Value |
| --- | --- |
| `Package/Identity/Name` | `33818Agosillo.MiaIAStudio` |
| `Package/Identity/Publisher` | `CN=0CEAE891-80E2-4EC8-9FD2-3AF0E024F85A` |
| `Package/Properties/PublisherDisplayName` | `Agosillo` |

The application declares `Microsoft.VCLibs.140.00.UWPDesktop` because the
Unreal executable dynamically uses the Microsoft Visual C++ runtime. Microsoft
Store installs this framework dependency with the application.

## Create the package

First create a fresh Shipping archive. This command can write directly to a
drive with sufficient free space. Set both Wit.ai **Client Access Tokens** in
this temporary PowerShell process if the Store build should provide the shared
English and Italian assistants. Never use or package a Server Access Token:

```powershell
Set-Location .\MiaIA\IDE\Unreal

$env:MIAIA_WIT_TOKEN_EN = "YOUR_ENGLISH_CLIENT_ACCESS_TOKEN"
$env:MIAIA_WIT_TOKEN_IT = "YOUR_ITALIAN_CLIENT_ACCESS_TOKEN"

powershell.exe -NoProfile -ExecutionPolicy Bypass `
    -File .\Build\Package-Windows.ps1 `
    -Configuration Shipping `
    -OutputDirectory "D:\MiaIA-Releases\Windows-Shipping"
```

Convert that archive to an unsigned Store-ready MSIX:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
    -File .\Build\Package-StoreMsix.ps1 `
    -PackageVersion 1.0.2.0 `
    -SourceDirectory "D:\MiaIA-Releases\Windows-Shipping" `
    -OutputDirectory "D:\MiaIA-Releases\Store-1.0.2.0"
```

The Store package version is independent from the user-facing **MiaIA Studio
0.1 Alpha** version. It has four numeric parts, its first part cannot be zero,
and its fourth part must be zero because Microsoft Store reserves that part.
The `1.0.2.0` package is the Store package for this release. Every later
submission should use a higher version, for example `1.0.3.0`.

The script copies the Shipping runtime into an MSIX layout while omitting the
Unreal bootstrap launcher, prerequisite installers, symbols, archive manifests,
and saved development data. It keeps the Unreal runtime notices and the complete
`Licenses` directory. When the Shipping archive contains the generated
`MiaIAAssistant.ini`, it also keeps the runtime copy so the installed application
can use the two shared private Wit.ai apps. Shipping hides the token editor from
customers; changing an app or Client Token requires generating and publishing a
new package. Client tokens in a desktop package remain extractable, so monitor provider
usage and migrate to a controlled proxy if stronger rate limiting or revocation
is needed. The script detects the executable name generated by the
Shipping configuration (currently
`IDE\Binaries\Win64\MiaIAStudio-Win64-Shipping.exe`) and writes that precise
path into the generated manifest.

The final `.msix` is intentionally unsigned. Upload that file in the package
section of the Partner Center submission; Microsoft Store validates and signs
the certified package.

Before submitting a build with the online assistant, update the Store privacy
policy and certification notes to state that text entered while the explicitly
labelled online option is enabled is transmitted to Wit.ai/Meta for intent and
entity interpretation. The option begins disabled, confirmation replies are
handled locally, and MiaIA project, model, dataset, and checkpoint data are not
sent by this feature. Add microphone disclosure and the corresponding Windows
capability only when audio capture is actually implemented.

## Local test of the unpacked layout

The generated `Layout` directory can be registered for a local development
test without signing the MSIX. Developer Mode may be required. Install the x64
VC runtime framework supplied by the Windows SDK first if it is not already
installed:

```powershell
Add-AppxPackage `
    "C:\Program Files (x86)\Microsoft SDKs\Windows Kits\10\ExtensionSDKs\Microsoft.VCLibs.Desktop\14.0\Appx\Retail\x64\Microsoft.VCLibs.x64.14.00.Desktop.appx"

Add-AppxPackage `
    -Register "D:\MiaIA-Releases\Store-1.0.2.0\Layout\AppxManifest.xml"
```

Remove the local development registration before installing a Store-delivered
build:

```powershell
Get-AppxPackage -Name 33818Agosillo.MiaIAStudio | Remove-AppxPackage
```

Verify that the Start menu entry and window title both read **MiaIA Studio**,
the application launches and closes cleanly, model operations work, external
datasets can be opened, user-selected files can be saved outside the install
directory, and Help/About show the expected licensing information. Also verify
that the Assistant language selector is present, the online option begins
disabled, both English and Italian requests produce reviewed command proposals,
and no credential settings are visible. This first
assistant release accepts typed requests; it does not yet capture microphone
audio.

## First Alpha Partner Center submission

For the 0.1 Alpha release, prefer **direct link** visibility so the package is
available from the MiaIA page on `www.nonop.biz` without being discoverable in
Store search. Keep the price free. Complete the listing, age rating, privacy and
support fields, upload screenshots and the generated `.msix`, then submit it for
certification. Do not publish the direct link until certification succeeds and
the Store installation has been tested on a second Windows user profile or
machine.
